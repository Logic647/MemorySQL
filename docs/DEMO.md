# 60 秒 Demo 脚本(发布素材)

> 一句话:多个 AI agent 之间切换,记忆/项目上下文零丢失——数据全程在你本机。

## 拍摄前准备

- 录屏工具(如 OBS),1920×1080,字体放大到 16px+
- 两台 agent 并排:Hermes Agent CN Desktop + Codex CLI(或 ZCode)
- MemorySQL 运行中(`curl http://127.0.0.1:8642/health` 确认),库里已有真实会话与记忆
- 预先把这段话发给 Hermes:「用 MemorySQL 演示跨 agent 续接」

## 分镜脚本

| 时间 | 画面 | 台词/动作 |
|---|---|---|
| 0:00–0:10 | 双开 agent,左边 Codex 有历史会话 | 「你同时用三四个 AI agent,换一个就得重新铺垫背景——项目讲到哪、你有什么偏好、踩过什么坑,全部重来。」 |
| 0:10–0:25 | 右边 Hermes 新会话,输入「续接 MemorySQL 项目」 | agent 自动调 `memory_get_context` —— 展开返回:开发者画像、长期记忆、项目状态、最近会话(带 id)、**上一棒交接摘要**。台词:「新会话第一次调用,全部上下文一次拉齐,连上一个 agent 干到哪都内联进来了。」 |
| 0:25–0:40 | 继续:「查一下怎么把知识库迁移到另一台机器」 | agent 调 `memory_search`,字面未命中 → **语义召回**补足(·语义 标注)。台词:「字面搜不到的概念性提问,本地向量模型兜底,全程不联网。」 |
| 0:40–0:55 | agent 收工:调 `memory_log_progress` | 台词:「干完活,agent 老实填一张收工表——做了什么、下一步、卡在哪——变成待确认进度,人一点头就进正式记忆。」随后任一 agent `memory_get_project_brief` 展示交接简报。 |
| 0:55–1:00 | MemorySQL 主界面(托盘图标) | 「数据 100% 存本机,除 LLM API 外零服务器。开源,地址在简介。」 |

## 备选镜头(素材)

- 托盘秒搜:任意界面 Alt+Shift+M → 输入关键词 → Enter 直达会话
- 自动项目日志:`vault/devlog/<项目>.md` 逐日时间线
- 记忆冲突检测:记忆页一键 → 矛盾对人工裁决
