# v0.7.0

> 这一版的主题一句话:**让 agent「少读会话、多读结论」,并顺手把安装包再瘦了一圈。**

发布页:https://github.com/Logic647/MemorySQL/releases/tag/v0.7.0

## 项目滚动总结:接手一个项目,读一份总结就够了

之前 agent 想接手一个项目,要么读交接简报(从最近会话现场拼的),要么自己翻会话——项目越大越翻不动。v0.7.0 新增**滚动总结**:每个项目定期把「上一版总结之后的新会话」消化成一份 **摘要 + 待办 + 决策**,滚动续写——过时的删掉、新信息并入,不是流水账追加。

总结按「写给对项目一无所知、即将接手的 agent」的标准写,必含五项:**项目是什么 / 技术要点与结构 / 关键决策与坑 / 当前进度 / 环境与命令**,上限 1500 字。首次开启会一次性消化该项目的**全部历史会话**(20 个/批连续消化,单次上限 200 个防失控),之后只读增量。总结里识别出的可沉淀事实,会作为候选记忆进入现有的「候选 → 确认」链路。

agent 侧对应一个新 MCP 工具 `memory_get_project_digest`(工具总数 7 → 8),读这一份即可接手;`memory_get_project_brief` 交接简报也会置顶引用它。

**默认关闭。** 隐私三条线,想走哪条走哪条:

- **不开** = 什么都不发生:不挂自动触发、界面不渲染总结、MCP 工具返回开启指引
- **开了 + 配了 LLM** = 会话素材**先本地脱敏,再发给 LLM**
- **开了 + 没配 LLM** = 纯本地规则总结,**零外发**

触发是自动的:会话摄入后按项目防抖(默认 30 分钟安静期,可调);长期未总结的项目开机后补跑。也随时手动——会话页项目组头的「总结」按钮、设置页「立即总结全部项目」、顶栏新增的「项目总结」弹窗(左列项目与状态,右列最新总结全文)、CLI `--digest`。产物落 `vault/digest/<项目>.md`,数据库为权威源。

## LLM 引擎聚合:免费 API 一键预置

项目总结、会话摘要、记忆精炼现在共用一个「LLM 引擎」,内置预设:

| 预设 | 模型 | 说明 |
|---|---|---|
| 智谱 GLM | glm-4.7-flash | 免费 |
| SiliconFlow 免费档 | Qwen/Qwen3-8B | 免费 |
| DeepSeek | — | 付费 |
| MiMo | mimo-v2.6-flash | 认证/参数兼容已适配 |
| 本地反代 | `127.0.0.1:8787/v1` | 免 key,配 opencode2api / CLIProxyAPI 等反代工具,模型列表动态拉取 |
| OpenAI 官方 / 自定义 | — | 任意 OpenAI 兼容端点 |

「测试连接」会真发一次补全请求,而且测的是**你正在填的这份草稿**——旧版读的是已保存配置,没保存过就永远报「配置不完整」,已修。LLM 不可用时,所有用到它的功能自动降级回本地规则,不阻塞任何流程。

## 界面整理

- **插件分组折叠**:设置页插件按七组收纳(核心数据 / 摘要引擎 / 会话捕获 / 项目与记忆 / 检索与服务 / 同步与备份 / 系统),默认只展开「核心数据」,外部插件单独成组
- **会话按项目折叠**:点项目组头折叠/展开,状态记住;配合顶栏「项目总结」弹窗
- **Agent 栏只显示检测到会话的 agent**:0 条的不再占位显示(「捕获状态」诊断区保留全量,装好某个 agent 后自动出现)

## 安装包:105.5 → 99.5 MB,语义组件改按需下载

| | v0.6.x | v0.7.0 |
|---|---|---|
| Windows 安装包 | 105.5 MB | **99.5 MB** |
| app.asar | 15 MB | **8 MB** |
| 语义推理组件 | 随包分发 | **首次启用时下载(11–25 MB,按平台)** |

语义检索的本地推理栈(onnxruntime + fastembed,全程离线)从安装包里拆出来了,和 embedding 模型一样改为**按需下载**:开启语义检索时自动拉取对应平台的组件包,下载完即时装载,无需重启;不用语义检索的用户永远不用下。

排查时顺带发现:npm 的 onnxruntime-node 在 Linux 上竟然自带一个 **327 MB 的 CUDA 后端共享库**,CPU 推理根本不会加载——组件包已排除,否则 Linux 组件包会膨胀到 230 MB。三平台组件包实测:Windows 11.0 MB / Linux 20.9 MB / macOS(arm64) 25.4 MB。

## 升级说明

- 数据零变化,升级后所有会话、记忆、项目状态原地保留
- Windows / Linux / macOS 自动更新直达
- **用过语义检索的用户**:升级后首次使用会提示下载语义组件(一次性,11–25 MB)
- 项目总结默认关闭;想要的话去 设置 → 项目总结 打开,不配 LLM 也能用(纯本地规则总结)

## 附:Tauri 迁移评估结论

本版立项时同步评估了换 Tauri 栈(壳确实能小到 ~4 MB)。实测结论是**不迁**:安装包大头是 Electron 底座(约 85 MB 压缩后),renderer 产物只有 0.68 MB,换栈对体积收益有限;内存也并不省(WebView2 多进程并不比 Electron 轻),而代价是全部重写。评估文档留了数字存档与三条重评触发条件:[docs/tauri-feasibility.md](../tauri-feasibility.md)。
