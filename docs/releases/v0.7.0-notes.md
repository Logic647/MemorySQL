# MemorySQL v0.7.0 更新日志(2026-10-25)

> 上一篇帖子介绍过项目的整体思路,这篇只记录版本变化。v0.7.0 围绕一件事:**让 agent「少读会话、多读结论」**——另外安装包又瘦了一圈(105.5 → 99.5 MB)。

## 本次更新内容

### 1. 项目滚动总结(新增,默认关闭)

每个项目定期把「上一版总结之后的新会话」消化成一份 **摘要 + 待办 + 决策**,滚动续写——过时的删掉、新信息并入,不是流水账追加。

- 总结按「写给对项目一无所知、即将接手的 agent」的标准写,必含五项:**项目是什么 / 技术要点与结构 / 关键决策与坑 / 当前进度 / 环境与命令**,上限 1500 字
- 首次开启会一次性消化该项目的**全部历史会话**(20 个/批连续消化,单次上限 200 个防失控),之后只读增量
- 总结中识别出的可沉淀事实,作为候选记忆进入现有的「候选 → 确认」链路
- agent 侧新增 MCP 工具 `memory_get_project_digest`(工具总数 7 → 8),读这一份即可接手;交接简报 `memory_get_project_brief` 会置顶引用它
- 产物落 `vault/digest/<项目>.md`,数据库为权威源

**隐私三条线,想走哪条走哪条:**

| 模式 | 行为 |
|---|---|
| 不开启(默认) | 什么都不发生:不挂触发、界面不渲染、MCP 工具返回开启指引 |
| 开启 + 配了 LLM | 会话素材**先本地脱敏,再发给 LLM** |
| 开启 + 没配 LLM | 纯本地规则总结,**零外发** |

触发是自动的:会话摄入后按项目防抖(默认 30 分钟,可调),长期未总结的项目开机后补跑;也随时手动——会话页项目组头「总结」按钮、设置页「立即总结全部项目」、顶栏新增的「项目总结」弹窗、CLI `--digest`。

### 2. LLM 引擎聚合

项目总结、会话摘要、记忆精炼共用一个「LLM 引擎」,内置预设一键填好:

| 预设 | 模型 | 说明 |
|---|---|---|
| 智谱 GLM | glm-4.7-flash | 免费 |
| SiliconFlow 免费档 | Qwen/Qwen3-8B | 免费 |
| DeepSeek | — | 付费 |
| MiMo | mimo-v2.6-flash | 认证/参数兼容已适配 |
| 本地反代 | `127.0.0.1:8787/v1` | 免 key,配 opencode2api / CLIProxyAPI 等反代工具 |
| OpenAI 官方 / 自定义 | — | 任意 OpenAI 兼容端点 |

「测试连接」真发一次补全请求,且测的是**正在填写的草稿**(旧版读已保存配置,没保存过就永远报「配置不完整」)。LLM 不可用时一切功能自动降级回本地规则,不阻塞。

### 4. 安装包 105.5 → 99.5 MB,语义组件改按需下载

| | v0.6.x | v0.7.0 |
|---|---|---|
| Windows 安装包 | 105.5 MB | **99.5 MB** |
| app.asar | 15 MB | **8 MB** |
| 语义推理组件 | 随包分发 | 首次启用时下载(11–25 MB,按平台) |

语义检索的本地推理栈(onnxruntime + fastembed,全程离线)从安装包拆出,和 embedding 模型一样**按需下载**:开启语义检索时自动拉取对应平台组件包,下载完即时装载,无需重启;不用语义检索的用户永远不用下。

排查时顺带发现 npm 的 onnxruntime-node 在 Linux 上自带一个 **327 MB 的 CUDA 后端共享库**(CPU 推理根本不会加载),组件包已排除——否则 Linux 组件会膨胀到 230 MB。三平台组件包实测:Windows 11.0 MB / Linux 20.9 MB / macOS(arm64) 25.4 MB。

## 项目简介(没看过上一篇的看这里)

**MemorySQL** 是一个本地优先的桌面应用,解决一个问题:**你同时在用多个 AI 编码 agent,它们各有一套会话存储,藏得深、格式各不相同——换 agent 就要重新铺垫全部背景,想搜一条历史会话无从下手。**

三件事:

1. **捕获**:12 家 agent(Codex / ZCode / Claude Code / OpenCode / Hermes / Qwen Code / Kimi CLI / CodeBuddy / WorkBuddy / Qoder 等)各一个适配器,自动发现并解析会话,原始文件只读不改;加密/云端的走「导入对话」兜底
2. **存储**:全部入一个本地 SQLite(FTS5 全文 + 本地语义检索,中文友好),只在你机器上
3. **续接**:本机起一个 MCP 服务(8 个工具),任意 agent 连接后,新会话一句「续接 <项目名>」——画像、长期记忆、项目状态、最近会话、上一棒交接摘要一次到位

隐私模型一句话:**本地明文,出口脱敏**。入库不脱敏(本地界面和 MCP 全量可见),任何导出/外发路径必须过脱敏模块;LLM 全程是可选项,不配就纯本地规则。
