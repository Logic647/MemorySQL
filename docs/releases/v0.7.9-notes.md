# MemorySQL v0.7.9 更新日志(2026-11-23)

> 修复:**会话记录里"看不到自己说的话"**(harness 系统注入混进 user 角色);
> 修复:**语义检索恢复可用**(上游模型源已失效,改为 HF 镜像自备下载);
> 修复:**同一目录被拆成两个项目**(首次启动会合并存量);
> 新增:**演示库彻底隔离真实会话**(截图/宣传物料不再泄露);
> 以及一批按全功能测试报告修掉的缺陷。

---

## 修复:会话记录里"没有用户输入"

各家 agent 会把系统上下文/通知写成 `user` 角色的消息,真实输入被淹没
(真库统计:zcode 的 user 消息 **85.5%** 是这类噪声,codex 20.9%、mimocode 19.8%):

- 会话详情把这类消息标成 **「user · 系统注入」** 并降权显示(半透明、限高滚动),
  你自己说过的话一眼可辨;
- 项目总结的「用户诉求」、兜底标题、规则记忆提炼、MCP `memory_get_session`
  四处同步过滤 —— 总结不再把 `# Environment…` 当成你说的话;
- 规则记忆不再把英文系统提醒误判成偏好。

## 修复:语义检索完全不可用

上游模型源 `storage.googleapis.com/qdrant-fastembed` 已返回 403,而 fastembed 自带
下载会把错误响应体写成 `.tar.gz` 缓存并永久毒化(用户只看到 `TAR_BAD_ARCHIVE`)。

- 改为**从 HF 镜像(hf-mirror → 官方)直接下载模型文件**,校验 HTTP 状态/长度/内容后
  落盘;失败自动清半成品并换镜像(可用 `semantic-search:modelMirror` 配自建反代);
- 设置 → 智能引擎 → 语义检索:模型缺失时出现 **「下载模型(~100MB)」** 按钮;
- 实测:hf-mirror 8 秒拉完 94.8MB,重建索引 27/27 全部嵌入成功。

## 修复:同一目录裂成两个项目(升级首启会合并)

不同 agent 的 cwd 写法不同(`H:\桌面\X` 与 `H:/桌面/X`),过去会登记成两个项目,
导致项目总结/项目记忆各覆盖一半。现在:

- 项目路径写入前统一归一(分隔符、尾斜杠、盘符、UNC);
- **首次启动会把存量重复项目合并**(保留会话最多的那条,会话/记忆/总结全部改指过去);
  已在本机真库副本验证:MemorySQL 4→2、temp 4→2、money 3→2,行数守恒、无孤儿、可重复执行。

## 修复:项目总结的触发时机

- 安静期从**会话最后一条消息**起算,不再按"入库时刻"计时(批量入库晚于消息时,
  过去会在你重新开口前一分钟才跑);
- 到点还会复核一次:期间你又开口了就把闹钟顺延;子代理会话不再给项目排总结。

## 修复:设置文件被静默清空

`settings.json` 若带 UTF-8 BOM(记事本保存),过去会解析失败并**整份覆盖为空**
(插件开关、捕获水位、LLM 配置、同步身份全丢)。现在剥 BOM 后正常读取;
真损坏则把原文件备份成 `settings.json.corrupt-<时间戳>` 并记错误,不再静默覆盖。

## 修复:演示库/截图不再泄露真实会话

用于宣传截图的演示库,关闭名单改为从内置插件清单派生(覆盖全部 24 家捕获插件),
并加了「少于 20 家就拒绝生成」的断言 —— 宣传图只会含虚构数据。

## MCP:项目解析更准,更愿意主动调用

- 项目关键词改为三级解析:**精确同名**(换机多份登记)合并 → 路径段匹配 →
  子串兜底**只取最近活跃的一个**并列出其它候选。过去 `new-chat` 会把 6 月的
  `new-chat-7` 并进来,agent 拿着另一个项目的记忆回答;
- `memory_get_context` / `brief` / `digest` / `list_sessions` / `search` 在非精确命中时
  输出「项目解析」行,agent 能自查是否串了项目;
- `initialize` 指令改为「**任何新任务的第一步**就调 memory_get_context」,并补了工具
  选择速查(没有 digest 工具时用 brief);返回里也会说明项目是按什么方式匹配到的。

## 其他修复

- 会话列表改为**按最后消息时间排序**(还在聊的会话/项目浮顶,不再被当天一次性的
  探针会话压住);
- 项目总结弹窗:插件被禁用时给出「去设置开启」的提示,不再永久「加载中」;
- 记忆写入:同 kind/scope/项目下**完全相同的內容不再重复插入**;
- `memory_search` 漏传/错传参数(如用 `q` 而不是 `query`)现在明确报参数错误;
- `--reindex` 在语义检索未启用时提示去设置开启,而不是 `Unknown channel`;
- 设置页工具数改为实时读取,不再写死「8 个」;
- 跨设备同步:内容相同但**标题被改过**的会话现在会按更新时间合并(尊重本地锁定);
- 插件设置在保存后不再误报「需重启」(只有插件启停才需要)。

## 升级提示

- 首次启动会自动合并同一目录的不同写法项目,并规范化会话 cwd(一次性,幂等);
  建议升级前把 `%APPDATA%\memorysql\data\memory.db` 复制一份留底。
- 语义检索若之前一直失败,升级后到 设置 → 智能引擎 → 语义检索 点「下载模型」再重建索引。
- 安装包与三平台更新清单同步发布;mac 双架构清单已合并。
