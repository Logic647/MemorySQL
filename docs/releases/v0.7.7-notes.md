## 二、v0.7.7 更新内容

### 1. 记忆分层:全局记忆 / 项目记忆

- 记忆拆成两层:**全局记忆**(跨项目通用的画像 / 偏好 / 事实 / 决策)与**项目记忆**(只属于某个项目)。旧库里已关联项目的记忆自动迁移为项目记忆,不用手动处理。
- `memory_get_context` 的注入顺序改为:**全局记忆 → 项目记忆 → 项目信息 → 项目总结 → 最近进展 → 待办 → 最近会话**。
- 记忆带**访问热度**:注入与搜索命中时累计,常用条目优先注入。每个项目 80 条、全局 40 条上限,按「锁定 > 画像 > 热度」保留。
- `memory_write` 支持 `scope=global/project`(带 project 时默认写项目记忆);`memory_search` 的项目过滤覆盖项目记忆,全局记忆始终保留。

### 2. 项目记忆 LLM 自动整理(新插件 `memory-curator`)

- 每次**项目总结完成后**,LLM 自动把总结提炼成项目记忆与全局记忆,**自动生效**——不再需要逐条「确认候选」。
- 你**编辑过的条目自动锁定**,LLM 的更新/停用一律跳过;手动新增的记忆默认锁定;想恢复自动维护可解锁。
- 全局记忆从各项目记忆跨项目汇总(默认 24 小时一次),只提炼跨项目稳定的内容。
- 入口:设置 → 智能引擎 → 「项目记忆(LLM 自动整理)」(开关 / 上限 / 汇总间隔 / 每项目状态 / 手动立即整理)。隐私不变:发给 LLM 的素材先经**本地脱敏**;不配 LLM 时自动整理不运行,其余能力照旧。

### 3. 项目总结拆成「总览 + 最近进展」

- 总结分两段:`summary` 只留项目总览(目标 / 技术 / 关键决策 / 环境命令),**「最近做了什么」单独成段详细展开**——改了哪些模块、已知问题、下一步。滚动续写语义不变。
- `memory_get_project_digest` 与上下文注入同步带出「最近进展」;总结超过 14 天未更新会附提示(最新一份自动取代旧卡,即交接卡语义)。

### 4. 记忆页重构

- 信息层级改为**「项目 → 分类」**:左侧只保留范围(全部 / 全局 / 各项目),选中项目后展开该项目的画像 / 偏好 / 事实 / 决策计数;列表先按项目分组、组内再分小节。
- 移除 Agent 筛选栏与旧「LLM 精炼候选 / 确认候选」按钮(自动整理已取代批量确认,个别候选仍可用行内「启用」转正)。
- 已停用条目默认隐藏,标题栏「显示已停用」随时查看;「生成分发文件」成功后自动打开分发目录。

### 5. 修复

- **收工汇报候选跨项目泄漏**:项目总结素材、项目日志、交接简报三处补项目过滤,A 项目不再混入 B 项目的收工汇报。
- **多机同步与记忆分层冲突**:同步包升级 v2——项目记忆按项目落位(旧版会全部落成全局)、已停用条目不再在对端复活、锁定状态随包携带(旧格式包仍兼容)。
- **规则提炼候选洪流**:自动整理接管后,旧的规则提取候选自动停用,不再堆积(收工汇报候选保留,仍作总结素材)。

## 四、项目简介(没看过前文的看这里)

**MemorySQL** 是一个本地优先的桌面应用,解决一个问题:**你同时在用多个 AI 编码 agent,它们各有一套会话存储,藏得深、格式各不相同——换 agent 就要重新铺垫全部背景,想搜一条历史会话无从下手。**

三件事:

1. **捕获**:24 家 agent 各一个适配器,自动发现并解析会话,原始文件只读不改;加密/云端的走「导入对话」兜底
2. **存储**:全部入一个本地 SQLite(FTS5 全文 + 本地语义检索,中文友好),只在你机器上
3. **续接**:本机起一个 MCP 服务(8 个工具),任意 agent 连接后,新会话一句「续接 <项目名>」——画像、项目记忆、项目状态、总结、最近会话一次到位

隐私模型一句话:**本地明文,出口脱敏**。入库不脱敏(本地界面和 MCP 全量可见),任何导出/外发路径必须过脱敏模块;LLM 全程可选,不配就纯本地规则。
