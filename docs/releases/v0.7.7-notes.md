# MemorySQL v0.7.7 更新日志(2026-11-13)

> 新增:**记忆分层(全局 / 项目)+ LLM 自动整理**;项目总结拆分「总览 + 最近进展」;
> 记忆页重构;多机同步修复。升级不丢数据,旧记忆自动迁移。

---

## 新增:记忆分层(全局记忆 / 项目记忆)

- 记忆拆成两层:**全局记忆**(画像 / 偏好 / 事实 / 决策,跨项目通用)与**项目记忆**(只属于某个项目)。
  旧库里已关联项目的记忆自动迁移为项目记忆,无需手动处理。
- agent 每次 `memory_get_context` 的注入顺序改为:
  **全局记忆 → 项目记忆 → 项目信息 → 项目总结 → 最近进展 → 待办 → 最近会话**;
  记忆带访问热度,常用条目优先注入。
- `memory_write` 支持 `scope=global/project`(带 project 时默认写项目记忆);
  `memory_search` 的项目过滤覆盖项目记忆,全局记忆始终保留。

## 新增:项目记忆 LLM 自动整理

- 每次**项目总结完成后**,LLM 自动把总结提炼成项目记忆与全局记忆,**自动生效** ——
  不再需要逐条「确认候选」。
- 你**编辑过的条目自动锁定**,LLM 不会覆盖;手动新增的记忆默认锁定;
  想恢复自动维护可解锁。
- 每个项目 / 全局有上限(80 / 40),按「锁定 > 画像 > 热度」淘汰;
  全局记忆每日跨项目汇总一次。
- 入口:设置 → 智能引擎 → 「项目记忆(LLM 自动整理)」(开关 / 上限 / 汇总间隔 /
  每项目状态 / 手动立即整理)。隐私:整理时发送给 LLM 的素材先经本地脱敏。

## 项目总结:短总览 + 详细交接卡

- 总结拆成两段:`summary` 只留项目总览(目标 / 技术 / 关键决策 / 环境命令),
  **「最近做了什么」单独成段详细展开**(改了哪些模块、已知问题、下一步)。
- `memory_get_project_digest` 与上下文注入同步带出「最近进展」;
  总结超过 14 天未更新会附提示(最新一份自动取代旧卡)。

## 记忆页重构

- 信息层级改为**「项目 → 分类」**:左侧只保留范围(全部 / 全局 / 各项目),
  选中项目后展开该项目的画像 / 偏好 / 事实 / 决策计数;列表先按项目分组、组内再分小节。
- 移除 Agent 筛选栏与旧「LLM 精炼候选 / 确认候选」按钮(自动整理已取代批量确认,
  个别候选仍可用行内「启用」转正)。
- 已停用条目默认隐藏,标题栏「显示已停用」开关随时查看。
- 「生成分发文件」成功后自动打开分发目录(与导出备份一致)。

## 修复

- **收工汇报候选跨项目泄漏**:项目总结素材、项目日志、交接简报三处补上项目过滤,
  A 项目不再混入 B 项目(或无主项目)的收工汇报。
- **多机同步(sync-folder)与记忆分层冲突**:同步包升级为 v2 —— 项目记忆跨设备
  按项目落位(旧版会全部落成全局)、已停用条目不再在对端复活、锁定状态随包携带
  (旧格式同步包仍兼容)。
- **规则提炼候选洪流**:自动整理接管后,旧的规则提取候选自动停用,不再堆积在记忆页
  (收工汇报候选保留,仍作为总结素材)。

## 升级

- 更新包从 **GitHub Releases** 下载(`latest.yml` / `latest-mac.yml` / `latest-linux.yml`)。
- 升级不丢数据:`memories` 表自动迁移(加 scope / locked / 热度字段并回填),
  项目总结表自动补「最近进展」列。
- 从 v0.7.5 起为「先问下载、下完再问安装」两步确认;下载完成后可立即重启安装,
  或稍后退出应用时自动安装。
