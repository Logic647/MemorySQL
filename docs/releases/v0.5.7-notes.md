# v0.5.7

> 这一版没有新功能 —— 全部内容就一件事:**安装包瘦了 38%**。

## 安装包瘦身:169 MB → 105 MB

| | v0.5.6 | v0.5.7 |
|---|---|---|
| Windows 安装包 | 169.1 MB | **105.5 MB** |
| 安装后占用 | 639.9 MB | **356.5 MB** |

砍掉的都是运行时用不到的东西,功能一个没少:

- 随包分发的**其他平台二进制**(Linux/macOS 的语义推理库等,约 175 MB)
- SQLite 的 C 源码包(运行时只用预编译好的动态库)
- 55 个 Chromium 语言包里的 53 个 —— 只留**中文 + 英文**
- 两个只在编译期用到的渲染层依赖

**语义检索推理链路已在真机全量重嵌入验证**(CPU 路径,268 条记忆重建成功)。

语言包精简的唯一副作用:在非中文/英文的系统上,极少数 Chromium 内建菜单
(如右键菜单)会显示英文;应用自身界面文案不受影响。

Linux(`.AppImage` / `.deb` / `.tar.gz`)与 macOS(`.dmg` / `.zip`)安装包同样瘦身。

## 兼容性

- 数据零变化:升级后所有会话、记忆、项目状态原地保留
- Windows / Linux 从 0.5.6 及更早版本**正常自动更新**到本版,无需重装
- macOS 仍只提供 **Apple Silicon(`arm64`)** 安装包(托管 Intel runner 持续排不到队,
  与代码无关);Intel Mac 用户请从 Release 页手动下载,自动更新暂不可用
