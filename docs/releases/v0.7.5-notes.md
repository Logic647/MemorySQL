# MemorySQL v0.7.5 更新日志(2026-11-10)

> 体验修订:更新改为「先问下载、下完再问安装」;外观默认跟随系统;
> 模型列表下拉修复;会话 id 提亮;捕获矩阵扩到 24 家,未检测到的默认关闭。

---

## 更新流程(行为变更)

- **发现新版本不再自动下载**:横幅/设置页只提示「发现新版本 vX」,点「下载更新」才开始下载(此前 `autoDownload=true`,检测到即静默下载)。
- **下载完成后再询问安装**:下载结束才出现「立即重启安装」;点「稍后」则退出应用时自动安装(原有语义保留)。
- 下载失败可直接在横幅上「重试下载」,失败原因就地显示。
- 更新源仍是 **GitHub Releases**。曾计划改走阿里云镜像,实测**下载反而更慢**(ECS 带宽中转),本版起不再默认使用;服务端 `/updates` 路由保留备查,设置键 `updater:feed` 可显式指定自建 generic 镜像(失败自动回退 GitHub)。

## 外观

- **默认跟随系统**:未显式选择过主题的用户升级后按系统深色/浅色偏好显示(`ui:theme` 缺省值从 `dark` 改为 `system`)。显式选过深色/浅色的保持不变。

## 修复

- **未检测到的捕获插件默认关闭**:宿主在没有显式 `plugin.<id>.enabled` 时,按「源是否存在」决定默认启停。没装的 agent 不再在侧栏亮起、不挂 watcher、不扫描;装好该 agent 后下次启动自动启用。用户手动开关过的一律以设置为准。
- **设置页「会话捕获」补齐 24 家**:此前只列旧的 13 家,新增插件没有开关(侧栏有、设置没有)。
- **模型列表下拉为空**:设置 → LLM 引擎 → 「获取模型列表」后候选不显示。根因是旧实现用 `<datalist>` 且 list id 随输入长度变化,Chromium 会丢掉候选关联。改为显式候选面板(点击/聚焦展开,点条目填入)。
- **会话 id 提亮**:会话详情头部与列表里的 `#123` 由灰色改为正文色。
