## 新增

### 腾讯 WorkBuddy 会话捕获

- 新插件 `capture-workbuddy`:扫描 `~/.workbuddy/projects/**/*.jsonl`,并用 `workbuddy.db` 快照补标题 / 工作目录 / 创建时间
- watcher 同时监听对话 JSONL 与 SQLite 库(含 `-wal`/`-shm`),会话变更增量入库
- 连接向导一键写入 `~/.workbuddy/mcp.json` 的 `mcpServers.memorysql`

### Qoder CLI / Qoder CN 会话捕获

- 新插件 `capture-qoder`:同时覆盖国际版 `~/.qoder` 与中国版 `~/.qoder-cn` 的 `projects/**/*.jsonl`(Claude 兼容格式),`state.json` 补会话名与 cwd
- 支持 `QODER_CONFIG_DIR` / `QODERCN_CONFIG_DIR` 自定义配置目录
- 连接向导写入 `settings.json` 的 `mcpServers.memorysql`(或用 `qoder mcp add`)

### 其他

- capture 工厂 `watchPaths` 回调现接收 `sourceRoot`,自定义源目录与孪生根都能正确监听(已有适配器兼容)

**验证:** typecheck 零错,vitest 126:126。WorkBuddy / Qoder 本机未装,合成样本单测覆盖,装机后可再真机扫一次。
