## 修复

### 启动时检测不到新版本

- 启动检查改走 `api.github.com` 探测(不依赖常被墙的 `latest.yml`),失败写入错误状态并在应用壳显示更新横幅,不再静默吞掉
- 修状态机遮蔽:已确认有新版后,滞后的 `not-available` 不会再把可用性清掉
- 设置页更新状态四态互斥(已下载 / 下载中 / 下载失败 / 其他错误),与横幅一致

### 项目文件夹 / 会话重命名后不同步

- `content_hash` 相同时仍轻量 UPDATE `title` / `cwd` / `project_id`(含 FTS),外部 agent 改名或文件夹改名会跟上
- `ensureProject` 收养同父目录下 path 已失效的孤儿项目并 re-point 旧会话,不再叉出新分组
- `cwd` 仅在磁盘上真实存在时才采纳,防止陈旧路径把会话打回去
- `capture-opencode` 补数据库 watcher(含 `-wal`/`-shm`),会话变更增量入 库

**验证:** typecheck 零错,vitest 120:120。
