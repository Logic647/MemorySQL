# MemorySQL v0.7.4 更新日志(2026-11-07)

> 热修:Linux 上导入归档(.msqlv)必失败的 EXDEV 错误。

---

## 修复

### Linux 导入归档报 `EXDEV: cross-device link not permitted`

- **根因**:导入时完整性校验库写进 `/tmp`(Linux 上是独立 tmpfs),再 `renameSync` 挪进数据目录——跨设备 rename 被内核拒绝。Windows 上 tmp 与数据目录同盘,永远踩不到;Linux 一上来就必现。
- **修法**:staging 目录先建,校验库直接写进数据目录同一侧,校验后在**同目录内** rename(同设备,原子性不变)。校验失败时整个 staging 清掉,数据目录不留残留。
- 全仓 `renameSync` 逐个审计过:其余链路(启动换装/导出/更新)均无跨设备 rename。

其余内容与 v0.7.3 相同,详见 [v0.7.3 更新日志](v0.7.3-notes.md)。
