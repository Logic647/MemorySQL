# MemorySQL v0.7.6 更新日志(2026-11-12)

> 修复:扫描会话「卡住 / 新会话迟迟不出现」;新增 Claude Code 桌面版会话捕获;
> 设置页提示改为在对应设置项下方就地显示。

---

## 修复:扫描会话不再卡住,新会话及时入库

- **不再重复调用 LLM 总结老会话**:此前每次扫描都会把所有「没有自带标题」的会话重新送 LLM
  (Claude Code 108 条里 94 条每轮都重写,标题每次还不一样),新会话的入库排在几十次联网之后,
  表现就是「点了立即扫描一直转」。现在消息内容没变时直接沿用库里已有的标题/摘要;
  摘要调用另有 15 秒预算,超时先用规则标题入库。
- **立即扫描有进度、有回执**:按钮显示 `扫描中 3/16…`;完成后面板显示
  「新增 N 条会话 · 共读 M 条」(有插件失败会附「K 个插件失败」),并立即刷新会话列表
  与捕获状态,不再需要切换页面。
- **修复扫描被第一个禁用插件截断**:旧实现的启用表来自首次渲染的空对象,会去调用没有
  `scanNow` 的禁用插件,第一个异常就中断整轮;现在按最新启用表逐个执行,单个失败只计数。

## 新增:Claude Code 桌面版(Claude Desktop 的 Code 标签页)

- 桌面版 Code 会话与 CLI 使用同一份 transcript 格式,已并入「Claude Code / 桌面版」捕获,
  不需要单独开开关;若在 Desktop Settings 里改过 `CLAUDE_CONFIG_DIR`,也会扫描应用自己的
  会话存储目录。
- 同一会话在 CLI 与桌面端各有一份时按会话 id 去重,保留消息更完整的一份。

## 体验

- **设置页提示就地显示**:改哪项设置,结果显示在该项下方;切换左侧分类即清空,
  不再堆在页面末尾、也不跨页残留(插件/捕获/连接按每一行单独显示)。
- 连接 Agent 向导的项目根目录标签去掉示例路径,占位符换成通用的 `D:\projects\my-app`;
  捕获列表与向导标注「CLI / 桌面版」。

## 升级

- 更新包仍从 **GitHub Releases** 下载(`latest.yml` / `latest-mac.yml` / `latest-linux.yml`)。
- 从 v0.7.5 起为「先问下载、下完再问安装」两步确认;下载完成后可立即重启安装,
  或稍后退出应用时自动安装。
