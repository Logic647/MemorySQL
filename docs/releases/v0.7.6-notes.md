# MemorySQL v0.7.6 更新日志(2026-11-10)

> 体验修订:更新改为「先问下载、下完再问安装」;更新包改走阿里云镜像;
> 外观默认跟随系统;模型列表下拉修复;会话 id 提亮。
>
> **本版替代已撤回的 v0.7.5**:0.7.5 发布后发现问题 —— 新增的 11 家捕获插件在设置页
> 「会话捕获」里没有开关(侧栏却全部亮起)。本版补齐设置列表,并让**未检测到的 agent
> 默认关闭**(装好后自动启用;用户手动开关过的一律以设置为准)。

---

## 更新流程(行为变更)

- **发现新版本不再自动下载**:横幅/设置页只提示「发现新版本 vX」,点「下载更新」才开始下载(此前 `autoDownload=true`,检测到即静默下载)。
- **下载完成后再询问安装**:下载结束才出现「立即重启安装」;点「稍后」则退出应用时自动安装(原有语义保留)。
- 下载失败可直接在横幅上「重试下载」,失败原因就地显示。

## 更新包下载源:阿里云镜像(从 0.7.5 起)

- electron-updater 的 feed 默认指向 `https://watch.logic-yjb.top/updates`(阿里云 ECS),不再是 `github.com` 的下载链路 —— 国内拉 100MB 级安装包太慢。
- 镜像由 `tools/upstream-watch/server.mjs` 的 `/updates/*` 提供:`latest.yml` / `latest-mac.yml` / `latest-linux.yml` 与同名资产,全部按**当前 latest release 的资产清单**白名单转发(不是开放代理)。
- **镜像不可用时自动回退 GitHub provider**,更新链路不会因此失联。
- 设置键 `updater:feed` 可覆盖镜像地址;显式设为空字符串 = 强制走 GitHub。

## 外观

- **默认跟随系统**:未显式选择过主题的用户升级后按系统深色/浅色偏好显示(`ui:theme` 缺省值从 `dark` 改为 `system`)。显式选过深色/浅色的保持不变。

## 修复

- **未检测到的捕获插件默认关闭**(0.7.5 撤回原因):宿主在插件没有显式
  `plugin.<id>.enabled` 时按「源是否存在」决定默认启停;没装的 agent 不再在侧栏
  亮起、不挂 watcher、也不扫描。装好该 agent 后下次启动自动启用。
- **设置页「会话捕获」补齐 24 家**:此前只列了旧的 13 家,新增插件没有开关 ——
  侧栏与设置两处现在同一份清单。
- **模型列表下拉为空**:设置 → LLM 引擎 → 「获取模型列表」后候选不显示。根因是旧实现用 `<datalist>`,且 list id 按输入值长度/候选数量动态拼接 —— Chromium 在 list id 变化后会丢掉候选。改为显式候选面板(点击/聚焦即可看到,点击条目直接填入)。
- **会话 id 提亮**:会话详情头部与列表里的 `#123` 由灰色(`--msql-fg-dim`)改为正文色,深色主题下为白色,浅色主题下为深灰。

## 升级提示

- 0.7.4 及更早版本仍从 GitHub 下载 0.7.6 安装包(本版本才引入镜像地址);**从 0.7.6 起,后续更新走阿里云**。
