## 版本 A:直球工具分享版

标题:AI编程助手换一个就得重讲一遍背景?这个开源小工具治好了我的失忆症

正文:

现在电脑上常驻仨AI:Codex跑长活、ZCode日常、ClaudeCode摸鱼辅助。

最恶心的点:换一个接手,它对你项目一无所知,背景从头讲一遍。昨天讲完今天还得讲,我是老板还是复读机?

更恶心的是这几家聊天记录各存各家,格式五花八门,想翻上个月那次会话,直接大海捞针。

受不了了自己写了个玩意儿:**MemorySQL**,开源免费,就干三件事——

**① 12家AI的会话全自动抓进本地库**
Codex/ZCode/ClaudeCode/Cursor/Gemini/Qwen/Kimi这些,监听它们本地文件增量入库,原文件只读不碰,密钥文件直接跳过。

**② 检索是双保险**
全文搜索+语义搜索(本地小模型跑,不联网)。搜"换机器了数据怎么办"能给你翻出标题写着"迁移"的会话,字面没对上也能命中。

**③ MCP续接,这才是核心**
本机起个MCP服务,agent连上后新会话丢一句"续接XX项目",一次调用把你的画像、项目进展、最近会话、**上一个AI干到哪的交接摘要**全拉回来,直接接着干。

数据100%在本机SQLite,除LLM API(还是可选的)外零联网,语义搜索也是本地模型。Win/mac/Linux全平台,安装包才105MB。

GitHub搜 **MemorySQL**(MIT开源):
github.com/Logic647/MemorySQL

自己用的东西,不收费不卖课,有同样AI失忆症的兄弟自取,有问题issue见。

### 正文(纯文本,直接粘)

```text
上次在这发这个工具还是 0.6.0,一转眼 0.7.7 了。中间攒的东西有点多,一次说清。

先说这版(0.7.7)干了啥。

① 记忆分家:全局 / 项目

以前记忆是一锅乱炖,项目 A 的偏好和项目 B 的踩坑混在一起。现在分两层:全局记忆放跨项目通用的东西(你是谁、什么习惯),项目记忆只属于那个项目。老数据自动迁移,不用你动手。

② 记忆开始自己整理了

每次项目总结做完,LLM 会顺手把总结提炼成记忆,自动生效,不用再一条条点"确认候选"。
重点:你手动编辑过的条目会自动上锁,AI 不会覆盖;想让它重新接管就解锁。
每个项目最多 80 条、全局 40 条,按"锁定 > 画像 > 常用"保留。

③ 项目总结拆成两段

以前一大坨,现在上半段是项目总览(目标/技术/关键决策/命令),下半段单独写"最近做了什么"——改了哪些模块、有什么已知问题、下一步。换 AI 接手,读这一份就够了,相当于交接卡。

④ 记忆页重排

左边选范围(全部/全局/各项目),右边先按项目分组、组内再分画像/偏好/事实/决策。停用的条目默认藏起来,想翻再打开。

⑤ 几个真 bug 修了

最烦的是项目串味:A 项目的收工汇报跑到 B 项目去了,这次三处过滤补齐。另外多机同步包升级到 v2,项目记忆不会再全落成全局。

中间那七个版本顺手补一下:

- 支持的 AI 从 13 家干到 24 家了(Goose、Droid、Cline、Grok、MiniMax、Copilot CLI 这些都进了)
- 加了浅色主题,外观能跟随系统
- Claude Code 桌面版也能抓了
- 子代理会话不再刷屏,折叠在父会话下面
- 启动扫描最快提了 30 倍,不再卡首屏
- 更新改成两步:先问你下不下,下完再问你装不装

最后给没看过前文的人一句话:

MemorySQL 是个本地优先的 AI 编码助手记忆库。24 家 AI 的会话自动抓进本地 SQLite,本机开一个 MCP 服务,新 AI 上工说一句"续接某某项目",它把你的画像、项目记忆、项目进展、最近会话一次查回去。

数据全在本机,LLM 是可选项,不配就纯本地规则跑。

GitHub 搜 MemorySQL(开源免费):
github.com/Logic647/MemorySQL

Windows / Linux / macOS 都有安装包,Windows 安装包 99.5MB。
```
